# Natural_Language_Processing-Spam_Classification
Using spam message dataset which includes emojis, punctuations, (mainly spam and ham messages), we are using the logistic regression model to classify whether the message is spam or not. As the dataset is unbalanced we are using boosting model with 20 logistic regression model.

we used different vectorization techniques like BagofWords, TF-IDF, Word2Vec, N-Grams and created separate models for each to analyze the which one works perfect.
